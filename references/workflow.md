# 可复用执行流程

## 连接与任务清单

优先调用本技能的 Prism MCP 接口，见 [connection.md](connection.md)。接口未加载时使用 README 的 CLI 后备路径；不能将 MCP 注册配置存在当成当前会话已经接通。

不固定 Prism 版本。连接后 `prism_get_capabilities` 检测真实标题/版本、窗口类、当前语言和脚本菜单，`inspect` 检测实际文件格式。控件以发现结果为准，controls.md 中本次编号不是跨版本契约。其他语言无法匹配脚本菜单时在当前 GUI 打开，再根据当前控件继续；命令不受支持时按 GUI 导入/保存，不伪造兼容成功。

记录：源 Excel、sheet、源 Prism 项目、参考图、所有指标同图还是分图、分组顺序、原始重复值、排除依据、均值/误差线、标签精度、P 值需求、输出目录。未明确的误差线先检查参考图；分组、单位、实验重复定义确实无法推断时才询问。

连接时按唯一项目标题选择，不按“第一个 Prism”选择。列出已有模态窗口，先识别它们的内容；不要关闭用户的未保存项目来方便自动化。本次自己的临时副本可在保存/验证最终项目后关闭。

## 数据调查与准备

1. 只读打开 Excel 的缓存值和公式两份视图，确认 sheet、标题行、数值区、组列、重复编号列、单位、备注、合并单元格和填色。
2. 区分实验记录、底部备注和统计汇总行。配置明确的起止行，不把“注：标黄……”作为第五组或测量值导入。
3. 根据来源说明设置排除规则。本次黄色是 `FFFF00`，整行各数值格均标黄；脚本按数值格的填色排除，与源注释一致。别把所有文件的黄色都当成剔除规则。
4. 准备 grouped TSV：第一行处理组标题，每组标题后跟 R−1 个空字段；后续每行“指标名 + G×R 个原始值”。排除数值末尾加 `*`。若重复数不同，尾部留空，n 按实际有效值计算。
5. 使用 `.17g` 保留数值，不把原始值先舍入到两位小数。仅均值显示标签舍入。缓存缺失的公式先停在明确单元格，不能自行写零。
6. 生成 audit：源 SHA256、Excel 单元格、组与重复位置、原始值、排除状态、padding、n、mean、SD、SEM、两位小数标签。原始表精度及有效重复都要可追溯。

## 保护原项目并新增表

保存源项目的物理备份，`inspect` 记录全部 data/graph/info/analysis UID。备份尚未完成时不运行 ClearTable、DuplicateFamily 或导入。

快速路径：参考图直接连接简单 grouped 原始重复值表时，`DuplicateFamily "前缀_" CLEAR` → 新表 → `SetYReplicates R` → `Import "TSV路径", 0, -1`。新增表序号从 baseline 推导，执行后重新 inspect 确认；任何额外分析族都不能按一表一图假设继续。

复杂参考图：GUI 新建一张 grouped 表，选择原始重复值子列和 R 个重复。样式参考稍后用 Magic 复制，不先复制复杂分析族。表和图命名清楚，源原表不覆盖。

`ClearTable` 只在本次创建的表内使用，且可能保留原列标题。既有列数与目标组数不同会留下空数据集；优先新建结构正确的表，避免把旧错排结构继续累积成更多临时图。

所有指标同图的正确结构是 M 行 × G 数据集 × R 重复。不要重排成 G 行 × M 数据集，这会让图形按指标拆开，颜色也更难匹配。

## 一张合并图

GUI“现有数据的新图”选择本次新增表，选全部需要的处理数据集。取消“为每个数据集创建新图表”。图型为 grouped 摘要数据的交错柱形，绘图统计为用户/参考图规定的 mean+SEM、mean+SD 等。

根据数据确认范围。混合单位同图用“测定值”等中性 Y 名称，各指标已有单位保留在 X 名称中；未注明单位的辅助称量不加 g。不要靠 X 轴范围筛选 grouped 指标行。

Magic 选本项目的参考图，通过缩略图位置和标题共同核对。底部 ComboBox 只是画廊范围，不是具体图列表。选择字体、柱形外观、原点/外观和图例；坐标范围通常不复制，标题匹配关闭。自由文本、图纸、嵌入表和显著性比较关闭。颜色逐组核对，避免全部变成参考图第一个数据集的蓝色。

## 均值、轴长和图例

格式化图表 → 注解 → 柱内顶部 → 绘图的值 → 小数两位。方向竖排可以容纳长数字；自动颜色关闭后检查黑字是否清晰。

原始值范围差异大时，低柱标签可能被自动隐藏。高柱的五字符均值在横排时也可能因柱宽而隐藏。用“设置坐标轴格式 → 坐标框与原点 → 形状自定义 → 宽度/高度”调整轴长，之后固定标签字体。不要为了短柱不断切换整图方向、复制分图或盲目缩小到低于字体对话框允许的字号。

关键：Edit 必须实际聚焦、替换、Tab 提交，再 Apply/OK；回读并重开核对。仅 WM_SETTEXT 或替换文字可能显示已改，最终仍按旧值保存。本次宽度 24 cm 被页面限制为 21.59 cm，因此回读值比请求值更可靠。

图尺寸改变后检查所有 48 个标签和图例。必要时只重新复制图例格式，或微调 X 字号/距离。源字体和四组颜色保留；布局参数不是统计数据，可按可读性调整。不要把整个图一起按百分比放大当作单独增加纵轴长度。

## 核验、保存、重新打开

版本/格式后备：ZIP 布局符合本脚本才读取原生 CSV 和 EXCLUDED JSON。旧 `.pzf`、旧 XML `.pzfx` 或其他布局用软件自己的 ExportTable 导出带排除星号的 TSV，`prism_verify_export` / `prism_data.py verify-export` 核验；原表/原图保护改为 GUI 中记录的标题、数量、保存前备份和视觉核对，不声称做了 UUID 检查。若导出只给显示精度导致原始值核验不通过，明确标记精度限制，调整软件导出精度或取得可解析的原生格式再核验；不能只凭均值一致宣布原始值完全一致。

- 原生 data.csv 核对全部原始数值；JSON 的 replicate ranges/cellAttributes 核对 EXCLUDED；不是只检查 `.txt` 的显示精度。
- 逐指标、逐组核对 n 和两位小数均值，检查误差线定义和大小，检查单位与分组顺序。
- 导出唯一文件名 PNG：全部指标、全部颜色、全部数字、无残留旧数值、无未请求 P 值、字体正常、图例不遮挡、页面边缘不截断。
- 保存到工作副本；关掉仅本次创建的临时副本，重新打开最终文件再导出。重开前后少量抗锯齿像素差异不能自动等同数据变化；数值、文字、布局必须一致。
- 在 Prism 中恢复最终图，调整显示缩放到全图可见。CLI 输出“已加载脚本”不代表已经运行完成。

错误图清理首先走 GUI，并按 baseline 保护原图。必须做 ZIP 清理时只处理显式 UUID 清单，写新副本，清理 document 引用和对应 graphs 目录，绝不改未知 data.bin；随后用 Prism 重开验证。GUI/ZIP 保存可能引起版本迁移，原图 data.bin 哈希改变并不能单独证明样式被修改。

停止条件是以上核验通过；不是预算接近耗尽或图片已经生成。最终结果明确说明 n、误差线、排除依据和原文件保留情况。
