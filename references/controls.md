# 本次验证过的界面与命令

来源：2026-10-13 本机 Prism 11.0.0 (84) 中文版实操。以下是控件 ID，不是 HWND，也不是 GraphPad 官方 API。先读当前控件文字和下拉选项；界面、版本、活动窗口改变后重新发现。

## 数据/图形脚本

```text
GoTo G <参考图1-based序号>
DuplicateFamily "新族前缀_" CLEAR
GoTo D <本次新增表1-based序号>
SetSheetTitle "新增数据表标题"
SetYReplicates 12
Import "完整TSV路径", 0, -1
GoTo G <本次新增图1-based序号>
SetSheetTitle "合并图标题"
SetAxisTitle Y "测定值"
SetAxisTitle X ""
SetAxisLimits Y bottom 0
SetAxisLimits Y top 50
SetAxisLimits Y interval 10
ExportPNG "新的完整PNG路径"
Save "工作副本的完整路径.prism"
CloseScriptDialog
```

数值与序号仅示意，实际从数据与 baseline 推导。`.pzc` 和 TSV 用 UTF-8 BOM，保留真实换行及最终换行。`Import ...,0,-1` 是本次“组标题行+指标行标题”的已验证组合。无组标题行时曾用 `1,-1`，勿混用。`ExportTable ...,ALL` 本版本忽略 ALL；直接 ExportTable 后读取日志和原生 CSV。

`SetAxisLimits Y 0,50,10` 无效，bottom/top/interval 分开写。`SetAxisTitle X ""` 可清除标题；空格不是可靠清除方法。ExportPNG 对已有文件可能产生带数字的新名字，应主动使用唯一新文件名。

## 字体标准对话框

字体、字形、大小的 ComboBox ID 分别为 1136、1137、1138。实际输入是其 Edit 子控件（常见 ID 都是 1001，不能跨 ComboBox 随便选）。字形先读列表后按“粗体”设置，本次 Arial 的“粗体”是 6，“2”是斜体；索引不可硬编码。

本次字体对话框接受 4–144 磅。改成 3 磅出现了真实错误提示。最终均值用 Arial 粗体 5 磅，指标标签保留原字体、调整到 14 磅；这只是本次版面，不是通用字号。

## 菜单与工具栏

原生脚本打开命令本次 616 可用。Magic 菜单曾为 24322，柱外观 24327，坐标框 24330，页面翻转 24311。直接 PostMessage 其他菜单经常不生效或路由到错误窗口；优先实际截图中双击柱子/轴和当前对话框。

工具栏 536 曾是 Magic；545 实际触发 ANOVA，不能拿它当图形格式。HWND、按钮坐标、第二行第几个缩略图、缩放滑块 1=50%/2=75% 等都要当场核实。
