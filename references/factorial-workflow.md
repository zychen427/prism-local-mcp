# 独立 3×2 因子实验：逐指标 Prism 绘图

先按 [版本分流](version-routing.md) 确认路径。本文的 CLD 单族模板和 ZIP 批量生成步骤适用于 10.2 及以上且模板格式通过检查的情形；旧版按版本分流说明处理。

适用条件：三个行因素水平、两个列因素水平，每单元格独立观测且有效 n 相同、n≥2；完整双因素模型、六个单元格全部 15 对 Tukey 比较。检查实验单位、样本独立性与数据质量；重复测量、嵌套、非平衡设计、缺失值或模型改变不能直接沿用。配色、误差线和显著性方案按用户要求，不从列名猜测。

## 1. 导入准备

先 `prism_survey_excel`；记录 sheet、首末数据行、1-based 组列和样本列、数值指标列。通过提供的配置明确 label 到 `[行因素, 列因素]` 的一一映射。通过工具描述提供显式配置，填入 source_file、sheet、行列范围、六组映射和指标。Excel 的公式没有缓存值时先让用户的软件重算并保存。无说明的颜色不代表排除。`independent_observations: true` 必须来自设计确认。

```text
prism_prepare_factorial_data(output_dir="本次空输出目录", config={...})
```

输出每个指标的原始数据 TSV 与 `factorial_audit.json`：包含来源 SHA-256、原始单元格与样本 ID、排除、均值/SEM、三种 P 值、全部 Tukey 调整 P 值和字母。明确排除时值以 `*` 写入 TSV，之后必须在 Prism 中确认标记。默认不排除。输出目录已有同名文件时停止，先换目录。

来源包含多个工作表时，在各自空目录分别准备，再调用 `prism_combine_factorial_audits` 合并设计一致的审计；原 TSV 仍须保留。`prism_factorial_annotation_plan` 生成每个指标的 P 值文本和字母对照，但不负责图上写入。

## 2. 首次创建单族模板

在当前版本 Prism 新建 Grouped 表：行因素三个水平、列因素两个水平，子列为原始重复；从 `assets/synthetic_3x2.tsv` 导入模拟数据。选摘要数据的交错柱形，选择 mean ± SEM。设置两种颜色、X 轴组名、Y 标题、字体及图例。建议 Times New Roman 和粗体，中文由系统支持的字体回退。

对该表运行普通双因素方差分析，模型含交互作用，选择“不论行和列比较所有单元格平均值”，Tukey、alpha 0.05；在图上添加 Compact Letter Display。确认结果恰有 15 个比较，图中六根柱上的字母可见。P 值自由文本此时不要放模板，避免复制旧数字。用“系列/另存为系列”保存到专用模板项目，确保仅一表、一图、一分析。Prism 10.2 前的版本可能将 CLD 当静态文本，须检查本机行为，不能声称跟随数据更新。

此前已在 Prism 11.0.0.84 验证过的流程：3×2 grouped 表 → ordinary two-way ANOVA + all cell means Tukey → CLD → DuplicateFamily CLEAR → Import，新数据会更新分析与 CLD。不同版本/界面需要动态检查。不要把用户实验原值放入移交的模板；可用合成表，或由用户在本机建立。

## 3. 构建和执行

打开唯一模板窗口，保存并确认模板无未保存改动。连接到模板并指定新的可写输出目录。调用 `prism_build_factorial_script(session_id, audit_file, template_file, project_file, script_file)`。该工具读取保存的模板并检查表、图、分析链接及 15 对 Tukey 结果；它不证明 UI 中未保存的变化，也不验证柱图类型、样式或图上 CLD 位置。检查生成的命令序列后，调用 `prism_run_script`。生成的脚本先 Save 到新文件，之后只更改新副本；首个指标替换 D1，其余 DuplicateFamily，导入后自动更新。

执行后重新连接新项目，用 `prism_inspect_project` 检查数量和每个链接。保存前生成唯一预览文件名，避免已有文件自动加数字。当前脚本不自动向图中写 P 值文本。根据 audit 中每个指标的 `p_values` 逐图插入，标明行因素、列因素和交互作用；注明这是静态文字。字体与图例按参考图设置，不能因为选中了图形类型就声称已匹配。

## 4. 数值与视觉核验

`prism_verify_factorial_project` 核对 ZIP 原生表数值、图表和分析数据来源、三种因素 P 值、全部 Tukey 调整 P 值和 CLD 结果状态。当前版本遇到排除或物理重复子列补空会返回未通过，需按软件导出含排除标记的高精度 TSV 额外核验；图形上是否显示字母、P 值或字体不能从该返回值推断。

逐图导出并目视检查：六根柱和 3 对位置、每组 n、误差线 SEM、单位、标题、六个 CLD、三个正确的 P、颜色、图例、可读性。保存项目并重新打开，再重新导出/核对。动态 CLD 是多重比较字母；共享字母表示该 Tukey 比较未达到显著阈值，不等于证明两组相等。

## 5. 故障处理

- 列映射不清、缺失缓存、异常值、n 不平衡或独立性不确定：停止计算，汇报具体行列和原因。
- Prism Script 窗口未被识别：查看真实项目/对话框、`.log` 和是否存在部分输出。不得重复跑 `DuplicateFamily`。部分完成后恢复到备份或从已确认的位置继续。
- 模板的原生格式或分析结构不支持检查：使用 Prism GUI 和高精度原生导出逐步核验，不声称自动检测通过。
- 如果 Prism/Codex 的权限或交互桌面不同，可能看不到窗口；不要擅自启动新进程覆盖用户会话。
